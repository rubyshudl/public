## 隐私与安全边界

知识内容及源代码完全公开。个人档案不是云端账号：密码只用于当前浏览器内的加解密，不上传、不写入仓库，也没有找回功能。收藏、进度、错题和草稿加密后保存在`localStorage`。跨设备需手动导出并导入加密备份。

教材题目均为虚构业务；不应将个人简历、求职信息或真实业绩写入公开文件。测试身份也使用合成数据。

标记和收藏自动保存，草稿必须点击保存。导出和锁定等待已提交保存完成；删除使旧保存失效。新浏览器可直接导入备份；损坏存储不会被当作空档案覆盖。旧v1备份兼容新增知识点收藏字段，加密格式不变。不要用旧版客户端写回新档案，否则旧客户端可能不认识新增字段；更新前保留备份。

加密不是云登录或全面安全边界。解锁期间内容在内存和页面中为明文，同源脚本及恶意浏览器环境不在防护范围内。没有密码找回；请用长且唯一的密码，不要在草稿中填写企业保密资料。

旧版测试曾包含不适合公开的身份匹配字面量，本批从当前文件移除并改用合成测试。当前文件清理不等于Git历史清理，未自动重写历史。
