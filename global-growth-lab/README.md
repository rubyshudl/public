# Global Growth Lab

公开地址：<https://rubyshudl.github.io/public/global-growth-lab/>

商业分析、海外GTM与出海商业化的公开学习和实战知识库。

## 首版功能

- 三条学习轨道、九个基础模块；
- 面试题、笔试题和虚构商业场景题；
- 先独立作答，再展开参考框架；
- 随机抽题、收藏、完成状态、待复习队列和答题草稿；
- 使用Web Crypto（PBKDF2-SHA256＋AES-256-GCM）的本地加密个人档案；
- 加密JSON备份与恢复；
- 站内搜索和响应式布局。

## 隐私与安全边界

知识内容及源代码完全公开。个人档案不是云端账号：密码只用于当前浏览器内的加解密，不上传、不写入仓库，也没有找回功能。收藏、进度、错题和草稿加密后保存在`localStorage`。跨设备需手动导出并导入加密备份。

题目均为虚构业务，不包含个人简历、求职信息、雇主、客户或真实业绩。
